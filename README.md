# 🔬 LabSaúde - Portal de Análises Clínicas

Este é um site institucional moderno desenvolvido em **ReactJS** para um Laboratório de Análises Clínicas. O projeto foi construído em dupla, aplicando conceitos de componentização, roteamento SPA (Single Page Application), versionamento com Git/GitHub e design responsivo voltado para a área da saúde.

## 🛠️ Tecnologias Utilizadas
* **ReactJS** (Biblioteca principal)
* **Vite** (Ambiente de desenvolvimento rápido e leve)
* **React Router DOM** (Gerenciamento de rotas e navegação SPA)
* **CSS3** (Estilização com variáveis globais e layout responsivo)
* **SVG Nativo** (Ilustrações vetorizadas e animadas integradas ao código)
